# PriEdu AI

An AI-powered ecosystem for primary education.

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **AI**: Gemini 2.0 Flash via Vercel AI SDK
- **Styling**: Tailwind CSS & Shadcn UI
- **Database**: MongoDB via Prisma ORM
- **Infrastructure**: Cloudinary & Vercel

## Core Features
- **Socratic Tutor**: AI-driven inquiry-based learning.
- **Vision Specialist**: Handwriting recognition and grading for homework.
- **Analytics**: Knowledge Map and Gap analysis for teachers.

## Development
```bash
npm install
npm run dev
```
